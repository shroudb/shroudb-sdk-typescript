# ShroudbPulse TypeScript Client

TypeScript/Node.js client for the [ShroudbPulse](https://github.com/shroudb/shroudb-pulse) Observability plane for unified audit event streaming.

## Install

```bash
npm install shroudb-pulse-client
```

## Quick Start

```typescript
import { ShroudbPulseClient } from "shroudb-pulse-client";

const client = await ShroudbPulseClient.connect("shroudb-pulse://localhost");

// Issue a credential
const result = await client.issue("my-keyspace", { ttlSecs: 3600 });
console.log(result.credentialId, result.token);

// Verify it
const verified = await client.verify("my-keyspace", result.token);
console.log(verified.state); // "active"

client.close();
```

## Connection URI

```
shroudb-pulse://[token@]host[:port][/keyspace]
shroudb-pulse+tls://[token@]host[:port][/keyspace]
```

Examples:
- `shroudb-pulse://localhost` — plain TCP, default port 7099
- `shroudb-pulse+tls://prod.example.com` — TLS
- `shroudb-pulse://mytoken@localhost:7099/sessions` — auth + keyspace

## Connection Pool

The client maintains an internal connection pool. Tune it at connect time:

```typescript
const client = await ShroudbPulseClient.connect("shroudb-pulse://localhost", {
  maxIdle: 8,
  maxOpen: 32,
});
```

## Commands

- `client.actors(...)` — Most active actors
- `client.auth(...)` — Authenticate the connection
- `client.count(...)` — Count events matching filter arguments
- `client.errors(...)` — Per-operation error rates
- `client.health(...)` — Check server health
- `client.hotspots(...)` — Find hotspot resources with highest activity
- `client.ingest(...)` — Ingest a single audit event
- `client.ingestBatch(...)` — Ingest a batch of audit events
- `client.query(...)` — Query events with filter arguments
- `client.sourceList(...)` — List configured event sources
- `client.sourceStatus(...)` — Show per-source ingestion statistics


## Streaming Subscribe

Subscribe to real-time events on a channel:

```typescript
import { ShroudbPulseClient } from "shroudb-pulse-client";

const client = await ShroudbPulseClient.connect("shroudb-pulse://localhost");
const sub = await client.subscribe("my-channel");

for await (const event of sub) {
  console.log(event.eventType, event.keyspace, event.detail, event.timestamp);
}

// When done:
sub.close();
client.close();
```

Each subscription opens a dedicated connection. The returned `Subscription` object
implements `AsyncIterable<SubscriptionEvent>`, so you can use `for await...of` or
call the async iterator manually.
