# ShroudbTransit TypeScript Client

TypeScript/Node.js client for the [ShroudbTransit](https://github.com/shroudb/shroudb-transit) Encryption-as-a-service.

## Install

```bash
npm install shroudb-transit-client
```

## Quick Start

```typescript
import { ShroudbTransitClient } from "shroudb-transit-client";

const client = await ShroudbTransitClient.connect("shroudb-transit://localhost");

// Issue a credential
const result = await client.issue("my-keyspace", { ttlSecs: 3600 });
console.log(result.credentialId, result.token);

// Verify it
const verified = await client.verify("my-keyspace", result.token);
console.log(verified.state); // "active"

client.close();
```

## Connection URI

```
shroudb-transit://[token@]host[:port][/keyspace]
shroudb-transit+tls://[token@]host[:port][/keyspace]
```

Examples:
- `shroudb-transit://localhost` — plain TCP, default port 6499
- `shroudb-transit+tls://prod.example.com` — TLS
- `shroudb-transit://mytoken@localhost:6499/sessions` — auth + keyspace

## Connection Pool

The client maintains an internal connection pool. Tune it at connect time:

```typescript
const client = await ShroudbTransitClient.connect("shroudb-transit://localhost", {
  maxIdle: 8,
  maxOpen: 32,
});
```

## Commands

- `client.decrypt(...)` — Decrypt ciphertext using the embedded key version
- `client.encrypt(...)` — Encrypt plaintext with the active key version
- `client.generateDataKey(...)` — Generate a data encryption key (envelope encryption pattern)
- `client.health(...)` — Check server health
- `client.keyInfo(...)` — Get keyring metadata and key version information
- `client.rewrap(...)` — Re-encrypt ciphertext with the current active key version
- `client.rotate(...)` — Rotate the keyring to a new key version
- `client.sign(...)` — Create a detached signature
- `client.verifySignature(...)` — Verify a detached signature


## Streaming Subscribe

Subscribe to real-time events on a channel:

```typescript
import { ShroudbTransitClient } from "shroudb-transit-client";

const client = await ShroudbTransitClient.connect("shroudb-transit://localhost");
const sub = await client.subscribe("my-channel");

for await (const event of sub) {
  console.log(event.eventType, event.keyspace, event.detail, event.timestamp);
}

// When done:
sub.close();
client.close();
```

Each subscription opens a dedicated connection. The returned `Subscription` object
implements `AsyncIterable<SubscriptionEvent>`, so you can use `for await...of` or
call the async iterator manually.
