# ShroudbMint TypeScript Client

TypeScript/Node.js client for the [ShroudbMint](https://github.com/shroudb/shroudb-mint) Lightweight internal Certificate Authority.

## Install

```bash
npm install shroudb-mint-client
```

## Quick Start

```typescript
import { ShroudbMintClient } from "shroudb-mint-client";

const client = await ShroudbMintClient.connect("shroudb-mint://localhost");

// Issue a credential
const result = await client.issue("my-keyspace", { ttlSecs: 3600 });
console.log(result.credentialId, result.token);

// Verify it
const verified = await client.verify("my-keyspace", result.token);
console.log(verified.state); // "active"

client.close();
```

## Connection URI

```
shroudb-mint://[token@]host[:port][/keyspace]
shroudb-mint+tls://[token@]host[:port][/keyspace]
```

Examples:
- `shroudb-mint://localhost` — plain TCP, default port 6699
- `shroudb-mint+tls://prod.example.com` — TLS
- `shroudb-mint://mytoken@localhost:6699/sessions` — auth + keyspace

## Connection Pool

The client maintains an internal connection pool. Tune it at connect time:

```typescript
const client = await ShroudbMintClient.connect("shroudb-mint://localhost", {
  maxIdle: 8,
  maxOpen: 32,
});
```

## Commands

- `client.auth(...)` — Authenticate the connection
- `client.caCreate(...)` — Create a new Certificate Authority
- `client.caExport(...)` — Export the CA's public certificate
- `client.caInfo(...)` — Get information about a CA
- `client.caList(...)` — List all CAs
- `client.caRotate(...)` — Rotate the CA's signing key
- `client.crlInfo(...)` — Get CRL information for a CA
- `client.health(...)` — Check server health
- `client.inspect(...)` — Inspect a certificate
- `client.issue(...)` — Issue a new certificate
- `client.issueFromCsr(...)` — Issue a certificate from a CSR
- `client.listCerts(...)` — List certificates for a CA
- `client.renew(...)` — Renew a certificate
- `client.revoke(...)` — Revoke a certificate


## Streaming Subscribe

Subscribe to real-time events on a channel:

```typescript
import { ShroudbMintClient } from "shroudb-mint-client";

const client = await ShroudbMintClient.connect("shroudb-mint://localhost");
const sub = await client.subscribe("my-channel");

for await (const event of sub) {
  console.log(event.eventType, event.keyspace, event.detail, event.timestamp);
}

// When done:
sub.close();
client.close();
```

Each subscription opens a dedicated connection. The returned `Subscription` object
implements `AsyncIterable<SubscriptionEvent>`, so you can use `for await...of` or
call the async iterator manually.
