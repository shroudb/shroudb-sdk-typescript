# ShroudbSentry TypeScript Client

TypeScript/Node.js client for the [ShroudbSentry](https://github.com/shroudb/shroudb-sentry) Policy-based authorization engine.

## Install

```bash
npm install shroudb-sentry-client
```

## Quick Start

```typescript
import { ShroudbSentryClient } from "shroudb-sentry-client";

const client = await ShroudbSentryClient.connect("shroudb-sentry://localhost");

// Issue a credential
const result = await client.issue("my-keyspace", { ttlSecs: 3600 });
console.log(result.credentialId, result.token);

// Verify it
const verified = await client.verify("my-keyspace", result.token);
console.log(verified.state); // "active"

client.close();
```

## Connection URI

```
shroudb-sentry://[token@]host[:port][/keyspace]
shroudb-sentry+tls://[token@]host[:port][/keyspace]
```

Examples:
- `shroudb-sentry://localhost` — plain TCP, default port 6799
- `shroudb-sentry+tls://prod.example.com` — TLS
- `shroudb-sentry://mytoken@localhost:6799/sessions` — auth + keyspace

## Connection Pool

The client maintains an internal connection pool. Tune it at connect time:

```typescript
const client = await ShroudbSentryClient.connect("shroudb-sentry://localhost", {
  maxIdle: 8,
  maxOpen: 32,
});
```

## Commands

- `client.auth(...)` — Authenticate the connection
- `client.evaluate(...)` — Evaluate an authorization request against loaded policies
- `client.health(...)` — Check server health
- `client.keyInfo(...)` — Get signing key information
- `client.keyRotate(...)` — Rotate the signing key used for JWT decisions
- `client.policyInfo(...)` — Get information about a specific policy
- `client.policyList(...)` — List all loaded policies
- `client.policyReload(...)` — Reload policies from disk


## Streaming Subscribe

Subscribe to real-time events on a channel:

```typescript
import { ShroudbSentryClient } from "shroudb-sentry-client";

const client = await ShroudbSentryClient.connect("shroudb-sentry://localhost");
const sub = await client.subscribe("my-channel");

for await (const event of sub) {
  console.log(event.eventType, event.keyspace, event.detail, event.timestamp);
}

// When done:
sub.close();
client.close();
```

Each subscription opens a dedicated connection. The returned `Subscription` object
implements `AsyncIterable<SubscriptionEvent>`, so you can use `for await...of` or
call the async iterator manually.
