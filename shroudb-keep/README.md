# ShroudbKeep TypeScript Client

TypeScript/Node.js client for the [ShroudbKeep](https://github.com/shroudb/shroudb-keep) Secrets manager.

## Install

```bash
npm install shroudb-keep-client
```

## Quick Start

```typescript
import { ShroudbKeepClient } from "shroudb-keep-client";

const client = await ShroudbKeepClient.connect("shroudb-keep://localhost");

// Issue a credential
const result = await client.issue("my-keyspace", { ttlSecs: 3600 });
console.log(result.credentialId, result.token);

// Verify it
const verified = await client.verify("my-keyspace", result.token);
console.log(verified.state); // "active"

client.close();
```

## Connection URI

```
shroudb-keep://[token@]host[:port][/keyspace]
shroudb-keep+tls://[token@]host[:port][/keyspace]
```

Examples:
- `shroudb-keep://localhost` — plain TCP, default port 6899
- `shroudb-keep+tls://prod.example.com` — TLS
- `shroudb-keep://mytoken@localhost:6899/sessions` — auth + keyspace

## Connection Pool

The client maintains an internal connection pool. Tune it at connect time:

```typescript
const client = await ShroudbKeepClient.connect("shroudb-keep://localhost", {
  maxIdle: 8,
  maxOpen: 32,
});
```

## Commands

- `client.auth(...)` — Authenticate the connection
- `client.delete(...)` — Soft-delete a secret
- `client.get(...)` — Retrieve a secret (latest or specific version)
- `client.health(...)` — Check server health
- `client.list(...)` — List secret paths matching a prefix
- `client.put(...)` — Store a secret (creates a new version)
- `client.rotate(...)` — Re-encrypt the latest version under the current key
- `client.versions(...)` — Show version history for a secret


## Streaming Subscribe

Subscribe to real-time events on a channel:

```typescript
import { ShroudbKeepClient } from "shroudb-keep-client";

const client = await ShroudbKeepClient.connect("shroudb-keep://localhost");
const sub = await client.subscribe("my-channel");

for await (const event of sub) {
  console.log(event.eventType, event.keyspace, event.detail, event.timestamp);
}

// When done:
sub.close();
client.close();
```

Each subscription opens a dedicated connection. The returned `Subscription` object
implements `AsyncIterable<SubscriptionEvent>`, so you can use `for await...of` or
call the async iterator manually.
