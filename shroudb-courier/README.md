# ShroudbCourier TypeScript Client

TypeScript/Node.js client for the [ShroudbCourier](https://github.com/shroudb/shroudb-courier) Secure notification delivery pipeline.

## Install

```bash
npm install shroudb-courier-client
```

## Quick Start

```typescript
import { ShroudbCourierClient } from "shroudb-courier-client";

const client = await ShroudbCourierClient.connect("shroudb-courier://localhost");

// Issue a credential
const result = await client.issue("my-keyspace", { ttlSecs: 3600 });
console.log(result.credentialId, result.token);

// Verify it
const verified = await client.verify("my-keyspace", result.token);
console.log(verified.state); // "active"

client.close();
```

## Connection URI

```
shroudb-courier://[token@]host[:port][/keyspace]
shroudb-courier+tls://[token@]host[:port][/keyspace]
```

Examples:
- `shroudb-courier://localhost` — plain TCP, default port 6999
- `shroudb-courier+tls://prod.example.com` — TLS
- `shroudb-courier://mytoken@localhost:6999/sessions` — auth + keyspace

## Connection Pool

The client maintains an internal connection pool. Tune it at connect time:

```typescript
const client = await ShroudbCourierClient.connect("shroudb-courier://localhost", {
  maxIdle: 8,
  maxOpen: 32,
});
```

## Commands

- `client.auth(...)` — Authenticate the connection
- `client.channelInfo(...)` — Get subscriber count for a WebSocket channel
- `client.channelList(...)` — List all active WebSocket channels
- `client.connections(...)` — Get total WebSocket connections
- `client.deliver(...)` — Deliver a notification (decrypts recipient, renders template, sends via adapter)
- `client.health(...)` — Check server health
- `client.templateInfo(...)` — Get information about a specific template
- `client.templateList(...)` — List all loaded templates
- `client.templateReload(...)` — Reload templates from disk


## Streaming Subscribe

Subscribe to real-time events on a channel:

```typescript
import { ShroudbCourierClient } from "shroudb-courier-client";

const client = await ShroudbCourierClient.connect("shroudb-courier://localhost");
const sub = await client.subscribe("my-channel");

for await (const event of sub) {
  console.log(event.eventType, event.keyspace, event.detail, event.timestamp);
}

// When done:
sub.close();
client.close();
```

Each subscription opens a dedicated connection. The returned `Subscription` object
implements `AsyncIterable<SubscriptionEvent>`, so you can use `for await...of` or
call the async iterator manually.
